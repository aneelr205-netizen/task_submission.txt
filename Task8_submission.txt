What is a view ?
A view is a virtual table in MYSQL created from one or more tables using a SQL query. It does not store data seperately, it displays data from the original table.

Advantages of using view's :
improves security by restricting access to specific columns.
Simplifies complex SQL queries.
provides data abstraction 
helps in reusing SQL queries
Makes data easier to access and manage 

Differences between Table and View :
       
         Table :                                                        view :

Stores actual data                  |                           Does not store data seperately 
Data can be inserted directly       |                           Virtual table  
Faster for direct access            |                           Depends on original table 
independent object                  |                           Slighter slower 
Occupies physical storage           |                          Based on SQL query

EXCEPTIUON HANDLING USING TRY, EXCEPT, FINALLY :
try:
num1 = int(input("Enter first number: "))
    num2 = int(input("Enter second number: "))
    result = num1 / num2
    print("Result:", result)
except ZeroDivisionError:
    print("Error: Cannot divide by zero.")
except ValueError:
    print("Error: Invalid input.")
finally:
    print("Execution completed.")
